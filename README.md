# Loopstudios Landing Page

A responsive Loopstudios landing page built with HTML and CSS.

## Live Demo

[View Live Website](https://kailashsaini-dev.github.io/loopstudios-landing-page/)

## Features

- Responsive design
- Desktop, tablet, and mobile layouts
- Responsive navigation
- Modern landing page design
- Mobile-friendly layout

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Hover Effects
- CSS Pseudo-elements (`::before` & `::after`)
- CSS Transitions
- CSS Transforms (`scale()`)

## About the Project

This project was created to practice building a responsive landing page from a provided Frontend Mentor design. The layout adapts to different screen sizes for a better user experience.
